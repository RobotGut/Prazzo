# Prazzo

Painel de gestão jurídica web para advogados e escritórios. A aplicação centraliza o controle de clientes, acompanhamento de processos, prazos processuais, calendário de compromissos e lançamentos financeiros em uma interface leve e intuitiva. O sistema opera 100% offline e sem armazenamento em nuvem, garantindo total privacidade e segurança dos dados. Todas as informações ficam salvas localmente no dispositivo do usuário, que conta com 6 opções de exportação: Backup JSON, Exportar CSV, Compartilhar, E-mail, Copiar Dados e Impressão/PDF.

## Funcionalidades

- **Gestão de Clientes e Processos:** Cadastro completo com dados pessoais, números CNJ, varas/tribunais e status processual.
- **Controle de Prazos e Calendário:** Acompanhamento de próximas audiências, prazos e compromissos com suporte a visualização em calendário.
- **Módulo Financeiro:** Gestão de honorários a receber, valores quitados e controle de caixa.
- **Documentos e Modelos:** Acesso rápido a minutas padrão (Procuração Ad Judicia, Contrato de Honorários e Declaração de Hipossuficiência).
- **Armazenamento Local e Backup:** Dados salvos direto no navegador com múltiplas opções de exportação (JSON, CSV, PDF, Copiar e E-mail).

## Stack

- **Front-end:** HTML5, CSS3, JavaScript
- **Armazenamento:** Browser LocalStorage
